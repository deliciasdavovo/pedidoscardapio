# Fotos do cardápio

As fotos dos produtos agora são servidas **desta pasta** (`img/`), via GitHub Pages,
com caminho relativo (ex.: `img/foto.png`). Antes vinham do Cloudinary, que teve a
cota gratuita estourada.

## Como completar a migração

1. Baixe as fotos do Cloudinary: painel → **Media Library** → selecionar todas → **Download** (zip).
2. Suba **todos os arquivos abaixo** para dentro desta pasta `img/`, **mantendo o nome exatamente igual**.
   - Pelo site do GitHub: *Add file* → *Upload files* → arraste as fotos → confirme que estão em `img/` → *Commit*.
3. Pronto — o cardápio volta a mostrar as fotos.

> Enquanto uma foto não estiver aqui, o cardápio mostra um placeholder (fundo bege + biscoito) no lugar dela.
